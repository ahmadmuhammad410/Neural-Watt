## 📖 Overview

**Neural Watt** is a powerful mobile application built with Flutter that leverages data analytics and predictive modeling to help users understand their energy consumption. By providing historical data analysis, environment configuration mapping, and machine learning-powered predictions, Neural Watt aims to make energy management smarter and more accessible.

## ✨ Key Features

- **📊 Comprehensive Analytics**: Visualize energy consumption trends over time with interactive and insightful charts.
- **🔮 Energy Prediction**: Utilize advanced forecasting models to estimate future energy needs based on historical usage and configurations.
- **📁 Data Management**: Easily upload consumption data, handle missing data intelligently, and assess data quality.
- **⚙️ Environment Configuration**: Customize building/environment parameters to improve prediction accuracy.
- **📅 Schedule Management**: Configure holiday schedules and custom time periods to refine analytics.
- **🌓 Adaptive UI**: Features a sleek, responsive design with full support for both Light and Dark themes.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (latest stable version)
- Android Studio / VS Code with Flutter extensions
- Android/iOS Emulator or a physical device

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/Neural-Watt-main.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Neural-Watt-main
   ```

3. **Install dependencies:**
   ```bash
   flutter pub get
   ```

4. **Run the application:**
   ```bash
   flutter run
   ```
